# ODA artwork

These supplied images were generated for ODA. Imported from the owner's parallel art workflow; no artwork was generated by this code task.

WebP files preserve the complete source frame, use quality 82, and strip metadata. Main files are at most 1200 pixels wide; native delivery uses the 960 pixel variant. Backdrops and welcome include an 800 pixel variant; course, sound and account art include a 600 pixel variant. Account signup and signin also have independent wide compositions for desktop. Smaller sources are never enlarged. Account art falls back to the supplied welcome image. Existing licensed fallbacks retain their source and license notes in assets/oda/delivery/quotes/SOURCES.md and assets/oda/landing/SOURCES.md.
