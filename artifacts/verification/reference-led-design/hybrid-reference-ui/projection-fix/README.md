This follow-up repairs the reproduced P2 saved-display issue without changing the persistence system, migration behavior or UI design. When a learner completed a lesson and navigated to Today before IndexedDB committed, the previous hook read the provisional localStorage projection. Today could show 1/6 course lessons, 1/103 library lessons and lesson 2 next while the authoritative record still had lesson 1 incomplete. The original reproduction also demonstrated working abort recovery; no durable corruption was established. Its actual observations, screenshots and failed scratch parse run are preserved unchanged in `baseline-reproduction/`.

Changing the confirmed provider seed immediately replaces the old display, including when a queued read fails. Refresh requests coalesce; expired guarded notifications and unmounted or replaced readers cannot publish. The course editor's private optimistic draft and the save/rollback code are unchanged.

The application delta is the hook plus two one-line caller arguments. The only other source files added are three portable React first-render tests and an explicitly invoked native browser QA script. Mandatory `npm test` needs no Chromium installation. The browser command uses the supported configured, system or Playwright browser path and fails visibly if unavailable. Package manifests, locks, services, stores, workflow, narration, assets, theme, colours and logo are unchanged. All seven compiled CSS files match the prior reviewed c2 build exactly.
