## What was diagnosed and fixed

The actually inspected delivered Today desktop frame already showed “Read two pages” and “Start · just 2 minutes” with capitals; its title was entered by a synthetic review fixture. The exact separately reported lowercase primary label was not established from that frame. A real interface-owned obstacle-plan sentence began “then I will …”. Only this translated prefix is now sentence-cased; saved decisions, quoted plans, habit names, Notebook text, editor inputs and share payloads remain as authored. Tests cover EN/TR/ES, dotted/dotless Turkish I, punctuation/whitespace, acronyms, mixed-case names, numeric/empty input and unchanged plan payload. No blanket CSS capitalize was introduced.

Other concrete fixes:

- **P3 copy:** English “1 day written” and “1 kept promise”; Spanish “1 día escrito” and “Racha de 1 día”. Zero/plural and existing Turkish forms remain correct.
- **P3 desktop spacing:** Notebook saved-entry preview follows the calendar/search card by12px instead of the measured206.234px baseline gap. One desktop grid-row declaration changes; approved tokens, artwork and visual branding are untouched.
- **P2 filter usability:** result/no-match feedback and Clear filters sit beside search/date controls rather than beyond the writing column. Search/date/week/reset transitions preserve unsaved editor bytes. Turkish search now uses the chosen interface locale for dotted/dotless I, including when the browser locale is English.
- **P3 narrow dates:** the selected date, otherwise today when present, is revealed using only necessary horizontal scrolling in the existing week region.44px targets, keyboard operation, week choice, page position and drafts are preserved. Intentional horizontal course/date scrolling retains labels and hints; page-wide overflow is absent in tested widths.
- **P2 save feedback:** plan and Save for tomorrow retain their inputs after native save failure, show a translated retry alert and block duplicate pending submissions. Plan Cancel/Escape/backdrop dismissal is guarded while saving. Existing persistence and rollback code are unchanged.
- **P3 retry confirmation:** successful tomorrow retry replaces the stale storage-error toast with localized success only after the durable save completes. This additional issue was discovered in actual intermediate screenshots; those receipts were preserved before the final source/build run.
