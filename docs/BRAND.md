# ODA brand decisions

Owner decisions, updated on 3 October 2026 for the explicitly selected icon8 domino. Preserve these decisions in future changes.

- **Designer signature:** `Designed by Yahya`. Use this exact wording in English, Turkish and Spanish; do not translate it or replace it with `by AurelyStudio`.
- **App name:** `ODA`, without dots. The expanded name is `One Decision Away`.
- **Installed app name:** the phone home screen and desktop applications list must both display exactly `ODA`. Keep the web manifest's `name` and `short_name`, and the Apple mobile web app title, set to `ODA`. The expanded name may remain inside the website.
- **Selected logo:** icon8, the gold foreground domino with two ruby/burgundy dominos on a burgundy background. On 3 October the owner explicitly requested replacing the application logo with this selection. The original standalone source was unavailable; parent visual review accepted a high-resolution reference-guided reconstruction. `brand-assets/domino8/ODA-Icon8-Reconstruction-Master-1254.png` retains the exact reconstructed source bytes, SHA256 `49ebd132ec6f67282a95a9e941631fccfd3e1d72bd5049a45179c277dcf78a96`. Its supplied provenance/comparison make the distinction from the lost original explicit. No new font or global theme accompanies this logo change.
- **Every earlier brand is preserved:** C4 (`public/brand/oda-c4.png`, `oda-*-c4-v1-*`, `LogoC4.tsx`) and v2/v3/v4. Switch with `node scripts/brand.mjs domino8|c4|v2|v3|v4`; it swaps references (manifest, index.html, service worker, notifications, test), `src/brand/current.ts` and root icon aliases. C4/domino8/v4 also have archived native assets for the switch. Previous C4 selection remains in history; the current explicit domino choice supersedes it. Do not generate a new logo as part of ordinary interface changes.
- **Platform derivatives:** `node scripts/brand-domino8-assets.mjs` uses the existing installed Chromium/canvas workflow to resize the accepted master without cropping, redrawing or distorting the dominos. Ordinary/native icons are opaque square images without baked outer rounding; platforms supply masks. Maskable PWA icons contain the full master at 70% uniform scale so essential artwork fits the 40% safe circle. In-app marks use display-only rounded clipping, and lockups retain the ODA label. The existing iOS catalog references an opaque 1024 icon and three identical 2732 launch images; the full 520 artwork fits their centered portrait-visible area. Asset configuration is not proof of physical installation or App Store acceptance.
- **Visual direction:** an elegant, warm editorial workbook, with forest green and burgundy accents. Use the shared tokens in `src/styles/tokens.css` and reserve explanatory illustrations for learning and action.
- **Credit placement:** visible landing-page and settings signatures, with matching website metadata and install branding. The compact standalone signature is always `Designed by Yahya`.

Historical translation keys may retain the old studio name for compatibility. Their displayed values must use the current designer signature. Third-party licenses, legal notices and copyright attributions are not designer signatures and must not be rewritten.
